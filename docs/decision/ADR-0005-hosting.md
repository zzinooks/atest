# ADR-0005: 운영 호스팅

- 상태: 승인 (연습·시범 운영 기준)
- 작성 일자: 2026-11-04

## 결정
- 단일 VM + Docker Compose (Backend, PostgreSQL, Caddy). 연습·시범 운영은 Oracle Cloud Always Free VM.
- 요청 기반으로 잠드는 무료 PaaS(Render Free 등)는 쓰지 않는다: 스케줄러가 멈추면 미수신·저혈당 알림이 멈춘다.
- 실사용(가족 안전을 맡기는 단계)은 유료 VPS 로 전환한다. 전환 기준: 무료 VM 회수·장애 1회 발생, 또는 가족이 알림에 실제로 의존하기 시작할 때.

## 결과
- 비용 0원(도메인·Play 등록 제외)으로 운영 가능
- 24시간 가용성은 보장되지 않음 → 앱 안내, 외부 가동 감시, 백업으로 보완
