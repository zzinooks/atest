# ADR-0004: 혈당 알림 의미 규칙

- 상태: 승인
- 작성 일자: 2026-11-04

## 결정
| 종류 | 열림 조건 | 해소 조건 | 기본값 |
|---|---|---|---|
| URGENT_LOW | 값 ≤ urgent_low 또는 LO 플래그 | 값 > low | 54 |
| LOW | 값 ≤ low (URGENT_LOW가 아닐 때) | 값 > low | 70 |
| HIGH | 값 ≥ high 또는 HI 플래그 | 값 < high | 250 |
| RAPID_FALL / RAPID_RISE | 직전 15분(±2.5분) 측정값 대비 변화율 ≤ −rate / ≥ +rate | 변화율이 기준 안으로 | 2 mg/dL/분 |
| NO_DATA | 마지막 **측정 시각**이 no_data_minutes보다 오래됨 | 새 측정값 | 30분 |
| SYNC_ERROR | 데이터 소스 연속 3회 실패 | 동기화 성공 | - |

- 변화율은 소스가 준 추세값을 쓰지 않고 **저장된 측정값으로 직접 계산**한다 (소스별 기준이 다르고 UNKNOWN이므로).
- 기준값은 환자가 바꾼다. 앱은 "의료진과 상의해 정하세요" 안내만 하고 권고값을 계산하지 않는다.
- 재알림 30분, 쿨다운 15분.

## 결과
- 알림 피로를 줄이면서, 확인하지 않은 위험 알림은 반복된다.
- 한계: 서버·FCM이 멈추면 알림이 가지 않는다. 앱에 "알림 미수신 가능성" 안내를 상시 표시한다.
