## 결론
- 수집 이후의 전 과정(저장·가족 공유·알람·통계·Notion·운영)은 Backend 기준으로 실제 동작을 검증했다.
- **프로젝트 성공의 전제인 "실제 바로잰 Fit 데이터 수집"은 여전히 미검증**이다. 실기기 1대로 아래를 확인하면 다음 판단이 가능하다.

## 실기기 확보 시 첫 30분 체크리스트
1. Health Connect → 앱 권한에 바로잰 Fit(또는 삼성 헬스)이 혈당을 쓰는지 → 쓰면 앱 설정에서 연결, 원천 앱 선택
2. 바로잰 Fit 앱 설정에 xDrip 연동 메뉴가 있는지 → 있으면 xDrip+ → Nightscout 업로드 대상 `https://SECRET@<서버>/ns/<sourceId>/api/v1/`
3. 공식 앱 화면 값 10개와 서버 저장값(값·측정 시각) 대조, 지연 측정
4. 결과로 ADR-0002 갱신

## 사용자 조치가 필요한 항목
| 항목 | 필요한 것 |
|---|---|
| Android 앱 빌드 | 환경 설정에서 `dl.google.com` 허용, 또는 PC 의 Android Studio |
| Notion 실연동 | `api.notion.com` 허용 + 통합 토큰·DB ID |
| FCM | Firebase 프로젝트, `google-services.json`, 서비스 계정 키 |
| 배포 | VM(Oracle Free 등), 도메인 |
| 법적 | 개인정보 처리방침 작성, 의료기기 해당성 검토 |
