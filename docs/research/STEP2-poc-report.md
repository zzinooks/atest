# STEP 2 보고서 — 데이터 수집 PoC (가상 CGM 에뮬레이터 대체)

- 작성 목적: 수집 경로가 정확성·측정 시각·중복·누락·지연 요구를 만족하는지 수치로 검증
- 작성 일자: 2026-11-04
- 관련 STEP: 2 (ADR-0002)

## 1. 요구사항
마스터 프롬프트 STEP 2: 데이터 조회, 정확성, 측정 시각, 수집 지연. 실기기가 없어 에뮬레이터로 대체 (사용자 결정).

## 2. 상세 내용
검증 구조: 에뮬레이터(별도 HTTP 서버, 정답 데이터 보유) → `EmulatorCloudAdapter` → 정규화·저장(PostgreSQL) → 알람.
저장 결과를 에뮬레이터의 정답과 **ID 단위 1:1 대조**한다 (`backend/src/test/.../EmulatorEndToEndIT.java`).

## 3. 기술적 결정
- 폴링 시 `마지막 측정 시각 − 3시간` 재조회 + `(patient, source, external_id)` 유니크 → backfill·중복 동시 해결 (D-1, D-2)

## 4. 확인된 사실 (테스트 실측, 2026-11-04)
| 시나리오 | 저장 | 누락 | 중복 | 값 불일치 | 측정시각 불일치 | 기타 |
|---|---|---|---|---|---|---|
| 야간 저혈당 (5분 폴링, 4시간) | 336 | 0 | 0 | 0 | 0 | 저혈당 첫 측정 → 알림 생성 **5분**, LOW→URGENT_LOW→회복 후 해소, 가족 기기로 전송 |
| 장애 주입 (응답 중복 30%, 503 20%) + 업로드 중단 1시간 | 325 | 0 | 0 | 0 | 0 | 중단 구간 12건 전부 사후 회수, 과거값으로 알림 0건, 동기화 실패 0회(재시도로 흡수) |
| 신호 끊김 40분 | - | - | - | - | - | 미수신 알림 10:30 생성(마지막 측정 10:00 + 30분), 복구 후 해소 |
| 잘못된 자격증명 | - | - | - | - | - | 3회 연속 실패 → SYNC_ERROR, 복구 시 해소, 자격증명 응답·이력 노출 0 |

수집 지연(측정 → 서버 저장): 5분 폴링 기준 p50 300초. 업로드 중단 시나리오의 p95 3600초는 의도된 1시간 중단분.
운영 설정(1분 폴링)에서는 업로드 지연(1~3분) + 폴링(≤1분) → **약 2~4분**으로 예상 (실프로세스 확인: STEP 8 라이브 테스트에서 최신값 나이 3~7분).

## 5. 미확인 사항
- **실제 바로잰 Fit 데이터는 수집하지 않았다.** 이 결과는 수집 파이프라인의 정확성 검증이며, 실기기 경로(Health Connect·xDrip+) 가능 여부는 여전히 UNKNOWN.
- Health Connect 경로의 실제 지연 (WorkManager 최소 15분 주기 + 원천 앱 기록 지연)
