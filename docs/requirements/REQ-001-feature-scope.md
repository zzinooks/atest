### 2.3 통계 정의 (업계 합의 기준을 기본값으로, 환자가 변경 가능)
기준: International Consensus on Time in Range (Battelino et al., Diabetes Care 2019)
| 지표 | 정의 | 기본 목표 |
|---|---|---|
| TIR | 70–180 mg/dL 비율 | > 70% |
| TBR | < 70 비율 / < 54 비율 | < 4% / < 1% |
| TAR | > 180 비율 / > 250 비율 | < 25% / < 5% |
| 평균 · SD · CV | CV = SD / 평균 × 100 | CV ≤ 36% |
| GMI | 3.31 + 0.02392 × 평균(mg/dL) | 참고값 |
| 데이터 충족률 | 실제 측정 수 / 기대 측정 수(288/일) | ≥ 70% 일 때만 통계 신뢰 표시 |

목표값은 의료적 판단이 아니라 표시 기준이다. 환자/의료진이 정한 값을 우선한다.

## 3. 기술적 결정
