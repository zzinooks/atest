## 개인정보보호법 검토 (요약, 법률 자문 아님)
- 혈당 = 건강정보 = **민감정보(제23조)** → 별도 동의 필요: 가입 시 처리 동의, 가족 공유는 환자의 초대가 개별 동의, Notion 기록은 별도 동의 스위치로 구현.
- 국외 이전: Firebase(FCM)·Notion·해외 호스팅 사용 시 국외 이전 고지·동의 필요 → 개인정보 처리방침에 명시해야 함 (**미작성**).
- 안전성 확보조치: 접근통제·암호화·접속기록(감사 로그) 구현. 접속기록 보관 기간 등 고시 기준 충족 여부는 운영 전 재검토.
- 의료기기 해당성: 타인에게 저혈당 알림을 보내는 기능 → 식약처 디지털의료제품 분류 검토 필요 (**미검토**). 앱에 "의료적 판단 아님, 알림 미수신 가능, 응급 시 119" 상시 표시.
